## English renditions of the team's working records

The team kept its working records in Traditional Chinese; they are not part of this repository. Only the passages
that a published citation uses are rendered in English, in [`release/evidence_en/`](release/evidence_en/). Each file
names its source and the source's sha256 on line 1, keeps the source's line numbers (line N renders line N), and
copies every number verbatim; lines no citation uses are left blank.

## Folders

| Folder | Contents |
|---|---|
| [`release/benchmarks/`](release/benchmarks/) | raw records (`records.jsonl`), `results.json` and `summary.md` of every benchmark, red-team, cross-check, load, capacity, metamorphic and PriMock57 run cited here |
| [`release/evidence_en/`](release/evidence_en/) | English renditions (above) |
| [`research/temporal_benchmark/results/`](research/temporal_benchmark/results/) | temporal benchmark results read by the Scorecard |
| [`handoff_day1/ui/pages/shell/data/`](handoff_day1/ui/pages/shell/data/) | frozen result snapshots shown by the Scorecard inside the image |
| [`submission/`](submission/) | submission text, slides, architecture, hazard log, privacy threat model, sources |

Not included: the development history, the team's Chinese working notes, raw datasets, local validation run folders
(`release/validation_abd/`, git-ignored) and model weights.
